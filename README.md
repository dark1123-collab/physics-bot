# Physics Bot

Телеграм-бот-тренажёр по физике: викторина с кнопками, мгновенной проверкой ответа
(правильно/неправильно + объяснение) и личной статистикой в базе (SQLite).

## Файлы

- `bot.py` — сам бот (aiogram 3).
- `questions.py` — все вопросы по разделам. Чтобы добавить новый раздел, скопируйте
  один блок (например `"mechanics": {...}`) и замените ключ, `title` и список
  `questions` — код `bot.py` менять не нужно.
- `requirements.txt` — зависимости.
- `stats.db` — создаётся автоматически при первом запуске (база SQLite со статистикой
  ответов пользователей).

## Как запустить

### 1. Установите Python

Скачайте Python 3.10+ с [python.org](https://www.python.org/downloads/). На Windows
при установке обязательно поставьте галочку **«Add Python to PATH»**.

Проверка: откройте терминал (PowerShell на Windows) и выполните:

```
python --version
```

### 2. Получите токен бота у @BotFather

1. В Telegram найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (укажите имя бота).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

### 3. Вставьте токен в код

Откройте `bot.py` и замените строку:

```python
BOT_TOKEN = "ВСТАВЬТЕ_СЮДА_ТОКЕН_ОТ_BOTFATHER"
```

на реальный токен из шага 2.

### 4. Установите зависимости

В терминале, в папке проекта:

```
pip install -r requirements.txt
```

Если появится ошибка про отсутствие `pip` — переустановите Python, отметив опцию
«pip» при установке.

### 5. Запустите бота

```
python bot.py
```

Пока в терминале не выведется ошибок — бот работает. Найдите своего бота в Telegram
по имени, которое дали в BotFather, и отправьте `/start`.

**Важно:** пока окно терминала открыто, бот работает. Если закрыть терминал или
выключить компьютер — бот перестанет отвечать. Для проверки это нормально, но для
постоянной работы (чтобы ученики могли писать боту в любое время) нужен отдельный
сервер — см. раздел ниже.

## Как пользоваться ботом

- `/start` — приветствие.
- `/quiz` — выбрать раздел и начать викторину. После каждого ответа бот сразу
  показывает правильно/неправильно и объяснение, в конце — итоговый результат.
- `/stats` — посмотреть свою общую статистику (сколько вопросов решено, точность).

## Как добавить новый раздел вопросов

Откройте `questions.py` и скопируйте блок `"mechanics": {...}` целиком, вставьте
его в словарь `SECTIONS` рядом, задайте новый ключ (например `"thermodynamics"`),
новый `title` (например `"МКТ и термодинамика"`) и свой список `questions` в том же
формате (`text`, `options`, `correct` — индекс правильного варианта, `explanation`).
Перезапустите бота — новый раздел появится в `/quiz` автоматически.

## Постоянная работа (деплой на Railway.app)

Чтобы бот отвечал ученикам круглосуточно, не завися от вашего компьютера, его можно
бесплатно развернуть на [Railway.app](https://railway.app):

1. Зарегистрируйтесь на Railway (можно через GitHub).
2. Загрузите папку проекта в репозиторий на GitHub (или используйте Railway CLI для
   деплоя без GitHub).
3. В Railway создайте новый проект → «Deploy from GitHub repo» → выберите репозиторий
   с ботом.
4. В настройках проекта добавьте переменную окружения, например `BOT_TOKEN`, и
   замените в `bot.py` строку с токеном на чтение из окружения:
   ```python
   import os
   BOT_TOKEN = os.environ["BOT_TOKEN"]
   ```
5. Railway автоматически определит `requirements.txt` и запустит `python bot.py`.
   Бесплатного лимита Railway достаточно для такой нагрузки (учебный бот с
   небольшим числом учеников).

Если понадобится — могу расписать деплой на Railway подробнее, по шагам с
скриншотами описания полей.
