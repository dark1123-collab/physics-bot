# Вопросы бота

```
questions/
  ege/task01.py … task26.py    прототипы задания ЕГЭ с этим номером
  ege/theory_*.py              «📐 Формулы и теория» по темам
  oge/task01.py … task19.py    прототипы задания ОГЭ
  oge/task20m.py / 20t / 20e   №20–22: механика / тепловые / электричество
  grades_7_9.py                7–9 класс (разделы по темам)
  __init__.py                  сборка меню (Часть 1 / Часть 2 / Теория, марафон)
```

**Добавить задачу** — допишите словарь в список `QUESTIONS` нужного файла.
**Убрать задачу** — удалите словарь. Код бота трогать не нужно: номер с задачами
сам появится в меню, номер без задач показывается с пометкой «скоро».
«🔥 Хард марафон» и «📐 Только формулы» собираются автоматически.

## Формат вопроса

| поле | обязательно | что это |
|---|---|---|
| `text` | да | текст вопроса (можно HTML: `<b>`, `<i>`, `<code>`) |
| `options` | да | 4 варианта ответа |
| `correct` | да | индекс правильного варианта в `options` (с нуля) |
| `explanation` | да | короткое объяснение, показывается после ответа |
| `image` | нет | путь к картинке (график/схема), показывается с вопросом |
| `formula` | нет | формула в mathtext (`$...$`), рендерится картинкой после ответа |
| `source` | нет | источник («Банк ФИПИ», «Демоверсия 2026»), строкой под объяснением |
| `solution_image` | нет | картинка с готовым решением, показывается после ответа |

Задания с выбором утверждений / изменением величин делаем так: в `text` — условие,
утверждения и строки «Вариант 1: …» … «Вариант 4: …», в `options` —
`["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"]`.
